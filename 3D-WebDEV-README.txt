# 🌐 3D Web Development with GSAP

An interactive **3D web development project** built using **HTML, CSS, JavaScript, and GSAP**.
The project focuses on creating a modern, immersive web experience with smooth animations, scrolling effects, and interactive UI elements.

## 🚀 Technologies Used

* **HTML5** — Structure and semantic layout
* **CSS3** — Styling, layouts, and visual effects
* **JavaScript** — Interactions and dynamic behavior
* **GSAP (GreenSock Animation Platform)** — Smooth and high-performance animations
* **ScrollTrigger** — Scroll-based animations and transitions
* **Locomotive Scroll** — Smooth scrolling experience

## ✨ Features

* 🎨 Modern and immersive UI
* 🌀 Smooth scrolling experience
* ⚡ GSAP-powered animations
* 📜 Scroll-based animations using ScrollTrigger
* 🖱️ Interactive elements and transitions
* 📱 Responsive design
* 🌐 3D-inspired web experience
